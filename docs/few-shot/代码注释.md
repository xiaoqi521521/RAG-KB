# 代码注释 Few-shot 示例

本文件用于给 `docs/prompt/代码注释.md` 提供精简示例。使用时重点参考注释风格，不要机械复用示例中的类名、函数名或业务实现。

## 示例 1：函数/方法级注释

适用场景：新增核心函数、服务方法、工具方法时，说明职责、关键入参和返回值。

```python
def trim_context(chunks: list[RetrievedChunk], max_tokens: int) -> list[RetrievedChunk]:
    """按 token 预算裁剪检索上下文。

    Args:
        chunks: 已按相关性排序的候选 chunk 列表。
        max_tokens: 允许进入 Prompt 的最大 token 数。

    Returns:
        未超过预算的 chunk 子集，保留原始相关性排序。
    """
    selected: list[RetrievedChunk] = []
    used_tokens = 0

    for chunk in chunks:
        if used_tokens + chunk.token_count > max_tokens:
            break
        selected.append(chunk)
        used_tokens += chunk.token_count

    return selected
```

## 示例 2：核心流程分阶段注释

适用场景：一个方法串联多个业务步骤时，用阶段注释展示执行骨架。

```python
async def index_document(document_id: int) -> IndexResult:
    """执行单个文档的索引流程。

    Args:
        document_id: 待索引的文档 ID。

    Returns:
        索引结果，包含 chunk 数量、版本号和最终状态。
    """
    # 第一步：读取文档元数据，文档不存在时直接终止，重试也无法恢复。
    document = await document_repo.get_by_id(document_id)
    if document is None:
        raise DocumentNotFoundError(document_id)

    # 第二步：解析并分块，后续 Embedding 和引用溯源都依赖 chunk 元数据。
    pages = await loader.load(document.storage_path)
    chunks = chunker.split(pages, document_id=document.id, kb_id=document.kb_id)

    # 第三步：批量生成向量，避免逐条调用外部 embedding 服务造成过多网络开销。
    embeddings = await embedding_client.embed_batch([chunk.content for chunk in chunks])

    # 第四步：写入新版本 chunk 后再清理旧版本，避免失败时线上查询无可用数据。
    new_version = document.version + 1
    await chunk_repo.insert_new_version(document.id, chunks, embeddings, new_version)
    await chunk_repo.delete_old_versions(document.id, keep_version=new_version)

    return IndexResult(document_id=document.id, version=new_version, chunk_count=len(chunks))
```

## 示例 3：Why 注释与边界条件

适用场景：复杂判断、重试、降级、权限过滤、版本切换等非直观逻辑。

```python
async def rerank_or_fallback(query: str, candidates: list[RetrievedChunk]) -> list[RetrievedChunk]:
    """执行 Reranker 精排，超时或失败时回退到 RRF 结果。

    Args:
        query: 用户原始问题。
        candidates: 已经经过权限过滤和 RRF 排序的候选 chunk。

    Returns:
        Reranker 结果；如果 Reranker 不可用，则返回原始候选列表。
    """
    if not candidates:
        return []

    try:
        return await reranker.rerank(query, candidates, timeout_seconds=2)
    except TimeoutError:
        # Reranker 是增强链路，不应因为精排超时中断问答；回退到 RRF 可保证查询可用性。
        logger.warning("reranker timeout, fallback to rrf", extra={"candidate_count": len(candidates)})
        return candidates
```

## 示例 4：少写废话注释

适用场景：避免把代码字面含义翻译成注释，只解释业务意图或风险。

不推荐：

```python
# i 加 1
i += 1

# 设置状态为 DONE
document.status = DocumentStatus.DONE
```

推荐：

```python
# 所有 chunk 已写入后再标记 DONE，避免查询端读到状态完成但向量数据尚未就绪。
document.status = DocumentStatus.DONE
```
