# 允许检索权限审计日志记录有限标识

为了对齐参考资料并支持排查检索层权限过滤结果，本项目允许“检索层权限过滤”专用审计日志记录当前 `user_id` 和被过滤的 `denied_kb_ids`。该例外只适用于权限过滤审计事件，不扩展到一般权限日志、认证日志、业务日志或 Prometheus/Grafana 标签；JWT、问题、回答、文档正文、会话消息、文档 ID、对象路径和其他高敏感内容仍禁止记录。

## Consequences

- 过滤日志可以追溯哪个用户触发了哪些知识库范围过滤，字段必须限定为 `user_id`、`denied_kb_ids`、操作、结果、权限来源、数量、耗时和错误类型。
- `user_id` 与 `denied_kb_ids` 不得进入指标标签，避免高基数和跨系统泄露。
- 日志访问必须继续受生产日志权限和保留周期控制；该例外不改变查询 API 的 `403`、`404` 和 `503` 语义。
