# 采用知识库级逻辑隔离

本系统采用参考项目的知识库级逻辑隔离，而不新增独立租户实体：`kb_id` 是检索与文档资源的硬数据边界，用户和部门是授权主体，公开状态、用户授权、部门授权及系统管理员角色共同决定有效权限。该取舍与现有表结构和参考资料一致，避免在当前阶段引入组织租户、跨租户管理和数据迁移；所有检索 SQL 仍必须以已授权的知识库范围过滤，不能依赖 Prompt 或前端约束。

## Consequences

知识库归属部门不等同于访问授权，创建者通过一条局部 `ADMIN` 授权获得管理权。未来若需要组织级隔离，必须单独设计 `tenant_id`、身份目录归属、跨组织管理员和历史数据迁移，不能把部门字段直接当作兼容替代。
