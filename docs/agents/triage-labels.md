# Triage 标签

工程技能使用五种标准 Triage 角色。下表定义这些角色在本仓库 Issue Tracker 中对应的实际标签值。

| 技能使用的标准角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估和分类 |
| `needs-info` | `needs-info` | 正在等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求已经完整，可交给 Agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要由人工完成实施或决策 |
| `wontfix` | `wontfix` | 已决定不处理 |

当技能提到某个角色，例如“应用可交给 Agent 的标签”，应使用上表中对应的实际标签值。

如果本仓库未来采用不同的标签命名，只修改表格右侧的“本仓库标签”列即可。
