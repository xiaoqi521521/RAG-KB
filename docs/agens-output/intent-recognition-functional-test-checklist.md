# 意图识别模块前端联调测试方法

## 1. 测试目标

通过聊天页面输入不同类型的问题，确认系统能在回答前识别用户意图，并进入正确的前端交互分支：

- 知识库查询：检索后回答，并展示来源。
- 会话回顾：根据当前会话历史回答，不进行知识库检索。
- 通用对话：直接回答，并显示未经过知识库检索的提示。
- 混合问题：提示用户拆分问题，不生成混合回答。

本清单只覆盖意图识别及其对聊天页面的影响，不覆盖登录、知识库管理、文档上传、权限管理等基础功能。

## 2. 联调准备

1. 启动后端和前端，打开聊天页面。
2. 选择一个已有可检索内容的知识库，例如包含“年假申请流程”的知识库。
3. 确认浏览器开发者工具的 Network 面板可用，并勾选 Preserve log。
4. 准备一个全新的会话，以及一个已经产生过至少两轮问答的历史会话。
5. 每次发送问题后记录：
   - 页面是否出现“正在检索知识库...”或“已找到相关内容，正在生成回答...”
   - 页面是否显示来源档案
   - 回答下方是否显示未检索提示
   - 回答是否能引用当前会话历史
   - Network 中聊天请求是否完成或报错

## 3. 知识库查询意图

### 测试 KB-01：直接查询制度

操作：在新会话输入“年假怎么申请？”，发送。

预期：

- 回答前出现知识库检索相关状态。
- 回答内容针对知识库文档，而不是泛泛常识。
- 回答下方不显示未经过知识库检索的提示。
- 有命中内容时显示“查看检索档案”和来源数量。
- 点击引用编号可以打开对应来源档案。

### 测试 KB-02：知识库查询追问

操作：在 KB-01 完成后输入“需要准备哪些材料？”，发送。

预期：

- 系统理解“哪些材料”指上一轮的年假申请，不把问题当成脱离上下文的闲聊。
- 回答前仍出现知识库检索状态。
- 回答模式与上一轮一致，来源范围没有异常扩大。

### 测试 KB-03：知识库无命中

操作：输入知识库中明确不存在的问题，例如“公司是否允许养宠物？”，发送。

预期：

- 仍按知识库问题处理并出现检索状态。
- 最终显示“在知识库中未找到与该问题相关的内容。”。
- 不出现通用回答提示，不生成未经检索的常识补充。
- 不显示来源档案或引用编号。

## 4. 会话回顾意图

### 测试 META-01：回顾上一问

前置：先在同一会话完成“年假怎么申请？”。

操作：输入“我刚才问了什么问题？”，发送。

预期：

- 能回答上一轮问题内容。
- 不出现“正在检索知识库...”或“已找到相关内容...”状态。
- 不显示检索档案和来源数量。
- 不显示未经过知识库检索提示，因为这是会话回顾，不是通用闲聊。

### 测试 META-02：总结会话

前置：在同一会话完成两轮不同主题的问答。

操作：输入“请总结一下我们刚才的对话。”，发送。

预期：

- 总结只来自当前会话中已经出现的内容。
- 不重新检索知识库，不新增知识库引用。
- 刷新或重新打开历史会话后，该条内容不会被误显示为知识库回答。

### 测试 META-03：空会话回顾

操作：新建会话后直接输入“我刚才问了什么？”，发送。

预期：

- 页面显示“当前会话暂无可回顾的历史消息。”。
- 不出现检索状态、来源档案或通用回答提示。
- 页面不会白屏，仍可以继续发送下一条问题。

## 5. 通用对话意图

### 测试 GENERAL-01：闲聊

操作：输入“你好，介绍一下你自己。”，发送。

预期：

- 不出现知识库检索状态。
- 回答可以基于模型通用能力生成。
- 回答下方显示一次提示语：

  `这条回答没有经过知识库检索，内容仅供参考，请结合实际情况判断。`

- 回答正文中不重复出现同一提示语。
- 不显示来源档案和引用编号。

### 测试 GENERAL-02：写作或翻译

操作：分别测试“帮我写一段欢迎词。”和“把‘欢迎加入团队’翻译成英文。”。

预期：

- 两条问题都不出现检索状态。
- 能正常生成写作或翻译结果。
- 每条回答都只显示一次未检索提示。
- 上一条回答的提示语、来源和状态不会串到下一条消息。

### 测试 GENERAL-03：选中知识库但问题无关

操作：保持知识库选择不变，输入“解释一下 HTTP 是什么？”，发送。

预期：

- 仍按通用对话处理，而不是因为页面选中了知识库就强制检索。
- 不出现知识库检索状态或来源档案。
- 显示一次未检索提示。

## 6. 混合或不确定意图

### 测试 UNCERTAIN-01：知识库问题加写作请求

操作：输入“先告诉我年假怎么申请，再帮我写一段欢迎词。”，发送。

预期：

- 不出现知识库检索状态。
- 不生成只回答其中一半的内容。
- 显示固定提示：`你的问题同时包含知识库查询和通用问题，请拆分后分别提问。`
- 不显示来源档案、引用编号或未检索提示。

### 测试 UNCERTAIN-02：制度问题加翻译请求

操作：输入“公司的报销流程是什么？顺便翻译成英文。”，发送。

预期：

- 结果仍是拆分提示，而不是调用检索后自行完成翻译。
- 页面状态恢复正常，可以继续发送拆分后的问题。

### 测试 UNCERTAIN-03：拆分后分别发送

操作：先发送“公司的报销流程是什么？”，再发送“请把上一条回答翻译成英文。”。

预期：

- 第一条按知识库查询展示检索状态和来源。
- 第二条根据实际分类结果进入对应分支，不应错误复用第一条的来源展示。
- 两条消息的提示语和来源互不影响。

## 7. 前端展示和刷新验证

- [ ] 通用回答正文与未检索提示始终只显示一次。
- [ ] 刷新页面并重新打开历史会话后，通用回答仍只显示一次提示，正文没有提示语残留。
- [ ] 会话回顾消息没有知识库来源卡片。
- [ ] 混合问题没有来源卡片，也没有未检索提示。
- [ ] 知识库回答仍能正常显示来源档案和引用高亮。
- [ ] 发送新问题时，上一条消息的提示语、来源档案、检索状态不会显示到新消息。
- [ ] 流式回答期间点击停止后，页面可以继续发送问题，且不会把上一条意图的状态带入下一条。

## 8. 异常联调方法

### 测试 ERR-01：意图识别服务不可用

操作：在开发环境临时让意图识别模型调用失败，然后从页面发送任意问题。

预期：

- 页面显示明确的“意图识别服务暂不可用”错误。
- 不进入知识库检索，也不伪装成通用回答。
- 页面仍可恢复，修复模型后可以重新发送。

### 测试 ERR-02：模型返回非法分类结果

操作：让分类模型返回非 JSON、未知意图或带额外字段的 JSON，再发送问题。

预期：

- 页面显示服务不可用错误，而不是展示模型原始输出。
- 不出现检索状态、来源档案或错误的回答模式。

### 测试 ERR-03：网络中断

操作：发送通用问题或会话回顾问题后，在回答过程中断开网络。

预期：

- 页面显示连接异常提示。
- 不残留“正在检索”或无限加载状态。
- 恢复网络后可以继续发送下一条问题。

## 9. 联调结果记录模板

| 编号 | 输入问题 | 预期意图 | 实际表现 | 是否出现检索状态 | 是否显示来源 | 是否显示提示语 | 结果 |
|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  | 通过/失败 |

失败时补充记录：浏览器、前端版本、后端日志时间、聊天请求耗时、页面显示文本和 Network 请求是否完成。

## 10. 最小验收集

至少完成以下 8 条后，才可认为前端联调基本通过：

- [ ] KB-01 直接知识库查询
- [ ] KB-02 知识库上下文追问
- [ ] KB-03 知识库无命中拒答
- [ ] META-01 回顾上一问
- [ ] META-03 空会话回顾
- [ ] GENERAL-01 通用闲聊
- [ ] GENERAL-02 写作或翻译
- [ ] UNCERTAIN-01 混合问题拆分提示
