# 前端功能测试清单

> 用途：验证 React 前端与后端 RAG 管道联调是否完整可用。
> 覆盖：登录、知识库、文档索引、检索问答（含意图路由）、评估、成本监控、全局用量、权限隔离与异常降级。
> 更新基准：`7f39d2b`（评估 Token 桶拆分与每日用量 Gauge）。

## 0. 环境准备

- [ ] 后端依赖已安装：`uv sync`
- [ ] `.env` 已配置数据库、Redis、MinIO、百炼 API Key、RERANKER_ENDPOINT
- [ ] PostgreSQL 已按当前结构基线完成初始化
- [ ] 后端已启动：`uv run uvicorn app.main:app --reload --port 8000`
- [ ] 健康检查通过：`curl http://localhost:8000/api/v1/health`
- [ ] 前端已启动：`cd frontend && npm install && npm run dev`（默认 `http://localhost:3000`）
- [ ] 前端构建通过：`npm run build`

## 2. 知识库管理（/kb）

- [ ] 空库时展示"还没有知识库"空状态与"新建知识库"按钮
- [ ] 新建知识库：名称、描述、部门标识、公开读取开关均正常
- [ ] 必填项缺失（名称/部门标识）时表单校验拦截
- [ ] 卡片展示：KB 编号（KB-0001 格式）、名称、权限 Tag（READ/WRITE/ADMIN）、描述、授权主体、访问方式（公开读取/授权读取）
- [ ] 新建成功后列表刷新并出现新知识库
- [ ] 点击卡片进入对应知识库的文档页（URL 为 `/kb/{kbId}/documents`）

## 3. 文档管理（/kb/:kbId/documents）

- [ ] 上传前未选择文件时"上传并索引"按钮禁用
- [ ] 支持拖拽/点击上传，accept 限制为 `.pdf,.docx,.md,.txt`
- [ ] 选择不支持类型（如 `.xlsx`）时被文件选择框拦截
- [ ] 上传 PDF/MD/TXT/DOCX 各至少一份，均提示"文档已提交索引"
- [ ] 上传后状态流转：待处理 -> 索引中 -> 已发布（或 失败），有活动任务时显示"每 5 秒自动更新状态"
- [ ] 索引完成后 Chunk 数与 Token 数非空，文档列显示类型、大小、版本号
- [ ] 索引失败时文件名下方展示可读错误（解析服务不可用/空文档/向量化失败等），不直接暴露原始堆栈
- [ ] 表格展示：文件名、状态 Tag、Chunk、Token、上传时间、操作列
- [ ] 下载原始文档成功且内容一致
- [ ] 重建索引：确认弹窗后状态回到索引中，完成后版本号 +1，查询结果被新版本替换
- [ ] 删除文档：确认弹窗后文档消失，对应 chunk 不再被检索命中
- [ ] 无权限访问该知识库时（403/404）自动跳回 `/kb` 列表
- [ ] 统计卡片：总数 / 已发布 / 失败 数字正确

## 4. 检索问答（/chat）

### 基础问答

- [ ] 默认自动选中第一个知识库；支持多选，选项带权限后缀（名称 · 权限）
- [ ] 宽屏（xl+）知识库选择在左侧栏，窄屏移动到消息区顶部
- [ ] 输入框空内容时发送按钮禁用
- [ ] Enter 发送、Shift+Enter 换行；字数计数器到 2000（当前为展示值，未强制截断）
- [ ] 发送后用户消息与助手消息占位立即出现，显示"正在建立连接"

### 意图路由

- [ ] 企业知识问题走检索管道，状态帧显示检索/精排/生成过程
- [ ] 闲聊/常识类问题不检索知识库，回答下方附"这条回答没有经过知识库检索"提示
- [ ] 会话元问题（如"总结一下刚才的对话"）基于会话历史回答，不产生检索来源
- [ ] 知识库查询与闲聊混合的问题被引导拆分（提示"请拆分后分别提问"）
- [ ] 意图轮次写入历史会话；重新打开会话时提示语不重复追加

### 流式输出

- [ ] 状态帧逐条显示，生成内容逐 token 流式追加
- [ ] 结束后显示耗时（ms）与"查看检索档案 · N 条来源"，有来源时自动打开右侧档案
- [ ] 流式过程中点击"停止"可中断，随后可继续发送新问题
- [ ] 中断后再次提问不残留旧状态

### 引用与溯源

- [ ] 回答中的 [参考N] 渲染为引用印章，可点击并支持键盘操作，点击后右侧档案高亮对应来源
- [ ] 检索档案卡片展示：文档名、页码/章节、chunk 摘要、score
- [ ] 重新打开历史消息可再次查看其检索档案
- [ ] 引用编号与档案卡一一对应，无跳号或重复

### 拒答与防幻觉

- [ ] 提问知识库中不存在的内容时，回答为"在知识库中未找到与该问题相关的内容。"并显示"未检出"印章
- [ ] 拒答消息不显示引用编号，档案区显示"本次未检出可用来源"

### 多轮与历史会话

- [ ] 第一轮问答完成后左侧历史会话自动刷新，标题与时间正确
- [ ] 继续提问保持同一 session_id，多轮上下文生效（含追问）
- [ ] 点击历史会话可恢复消息与检索档案
- [ ] 历史会话支持删除（确认弹窗）；删除当前会话后消息区清空
- [ ] "新建会话"清空当前消息并开启新 session
- [ ] 切换账号后聊天内存状态被清空，不残留上一账号的会话与消息

### 回答反馈

- [ ] 助手消息生成后可点"有用/待改进"，图标状态即时切换
- [ ] 提交成功提示"已记录"；再次点击已选按钮取消反馈并提示"已取消反馈"
- [ ] 点击另一按钮可切换反馈；失败时图标状态回滚
- [ ] 刷新后（重新加载会话）反馈状态仍保留

## 5. 效果评估（/eval）

### 入口与权限

- [ ] 仅对至少一个知识库有 ADMIN 权限的账号可见侧边栏入口；无权限账号入口置灰并带锁图标
- [ ] 无权限账号直接访问 `/eval` 被重定向回 `/chat`
- [ ] 知识库下拉只展示具备 ADMIN 权限的知识库；无可选时显示"暂无评估权限的知识库"
- [ ] 非 ADMIN 知识库下显示权限不足横幅，运行/编辑/删除按钮禁用

### 标准问题集

- [ ] 数据集支持按状态筛选：全部（不含已归档）/候选/有效/待审核/已归档
- [ ] 添加问题：问题、期望答案、目标 chunk（多选，可搜索）、状态可保存
- [ ] 编辑回显原值并可修改；删除有确认且成功后刷新

### 运行评估

- [ ] 版本号自动生成为历史最大版本 +1，无需手填
- [ ] 无 ACTIVE 状态标准问题时运行被拦截并提示
- [ ] 运行中显示持续加载提示（含题数）
- [ ] 评估完成后最新报告展示：命中率@5、MRR@5、忠实度、答案相关性、上下文召回、上下文精度、拒答率
- [ ] 运行摘要展示：评估耗时、Token 总量、预估成本、题量、成功/部分成功/失败计数
- [ ] 历史表格按版本分页（每页 8 条），列含耗时、Token 总量、预估成本、检索样本数、命中数等
- [ ] 报告区版本下拉可切换查看历史版本，清空后回到最新
- [ ] 运行超过 5 分钟前端超时并提示减少题量或稍后重试
- [ ] 快速切换知识库/版本时旧请求结果不覆盖新选择

## 9. 异常与降级场景

- [ ] 后端未启动时前端有错误提示，不白屏、不卡死

- [ ] SSE 中途断连时前端在消息内提示"连接异常，请稍后重试。"
- [ ] 评估运行超时（约 5 分钟）有明确提示与恢复建议
