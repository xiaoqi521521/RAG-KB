# 前端功能测试清单

> 用途：验证 React 前端与后端 RAG 管道联调是否完整可用。
> 覆盖：登录、知识库、文档索引、检索问答、评估、成本监控、权限隔离与异常降级。

## 0. 环境准备

- [ ] 后端依赖已安装：`uv sync`
- [ ] `.env` 已配置数据库、Redis、MinIO、百炼 API Key、RERANKER_ENDPOINT
- [ ] PostgreSQL 已执行 `app/db/schema.sql` 及 `app/db/migrations/` 下迁移
- [ ] 后端已启动：`uv run uvicorn app.main:app --reload --port 8000`
- [ ] 健康检查通过：`curl http://localhost:8000/api/v1/health`
- [ ] 前端已启动：`cd frontend && npm install && npm run dev`（默认 `http://localhost:3000`）
- [ ] 前端构建通过：`npm run build`

## 1. 登录与路由守卫

演示账号（密码均为 `demo123`）：`admin`（系统管理员）、`hr001`（HR 部门）、`tech001`（技术部门）。

- [ ] 访问任意受保护路由（如 `/chat`）未登录时自动跳转 `/login`
- [ ] 使用 `admin / demo123` 登录成功并跳转 `/chat`
- [ ] 用户名或密码错误时提示"用户名或密码错误"，不跳转
- [ ] 刷新页面后登录态保持（localStorage token）
- [ ] 手动清空 localStorage 后刷新回到登录页
- [ ] 点击左下角退出按钮回到登录页，token 被清除
- [ ] 侧边栏展示当前用户名与首字母头像

## 2. 知识库管理（/kb）

- [ ] 空库时展示空状态与"新建知识库"按钮
- [ ] 新建知识库：名称、描述、部门标识、公开读取开关均正常
- [ ] 必填项缺失（名称/部门标识）时表单校验拦截
- [ ] 列表展示：KB 编号、名称、描述、权限 Tag（READ/WRITE/ADMIN）、授权主体、访问方式、创建日期
- [ ] 新建成功后列表刷新并出现新知识库
- [ ] 点击"文档"进入对应知识库的文档页（URL 为 `/kb/{kbId}/documents`）

## 3. 文档管理（/kb/:kbId/documents）

- [ ] 上传前未选择文件时"上传并索引"按钮禁用
- [ ] 支持拖拽/点击上传，accept 限制为 `.pdf,.docx,.md,.txt`
- [ ] 选择不支持类型（如 `.xlsx`）时被文件选择框拦截
- [ ] 上传 PDF/MD/TXT/DOCX 各至少一份，均返回"已提交索引"
- [ ] 上传后状态流转：PENDING -> PROCESSING -> DONE（或 FAILED），有活动任务时每 5 秒自动刷新
- [ ] 索引完成后 Chunk 数与 Token 数非空
- [ ] 表格展示：文件名、状态 Tag、Chunk、Token、上传时间、操作列
- [ ] 下载原始文档成功且内容一致
- [ ] 重建索引：确认弹窗后状态回到 PROCESSING，完成后版本号 +1，查询结果被新版本替换
- [ ] 删除文档：确认弹窗后文档消失，对应 chunk 不再被检索命中
- [ ] 无权限访问该知识库时（403/404）自动跳回 `/kb` 列表
- [ ] 统计卡片：总数 / 已发布 / 失败 数字正确

## 4. 检索问答（/chat）

### 基础问答

- [ ] 默认自动选中第一个知识库；支持多选知识库
- [ ] 未选择知识库时发送提示"请选择至少一个知识库"
- [ ] 输入框空内容时发送按钮禁用
- [ ] Enter 发送、Shift+Enter 换行，字数统计到 2000
- [ ] 发送后用户消息与助手消息占位立即出现，显示"正在建立连接"

### 流式输出

- [ ] 状态帧逐条显示（检索中/精排中/生成中……）
- [ ] 生成内容逐 token 流式追加，光标闪烁
- [ ] 结束后显示耗时（ms）与"查看检索档案 · N 条来源"
- [ ] 流式过程中点击"停止"可中断，随后可继续发送新问题
- [ ] 中断后再次提问不残留旧状态

### 引用与溯源

- [ ] 回答中的 [1][2] 编号可点击，点击后右侧检索档案高亮对应来源
- [ ] 检索档案卡片展示：文档名、页码/章节、chunk 摘要、score
- [ ] 重新打开历史消息可再次查看其检索档案
- [ ] 回答中引用的编号与档案卡一一对应

### 拒答与防幻觉

- [ ] 提问知识库中不存在的内容时，回答为"未找到相关内容"并显示"未检出"印章
- [ ] 拒答消息不显示引用编号
- [ ] 档案区显示"本次未检出可用来源"

### 多轮与历史会话

- [ ] 第一轮问答后左侧出现会话记录，标题与时间正确
- [ ] 继续提问保持在同一个 session_id，多轮上下文生效
- [ ] 点击历史会话可恢复消息、检索档案与所选知识库
- [ ] "新建会话"清空当前消息并开启新 session

### 回答反馈

- [ ] 助手消息生成后可点"有用/待改进"，图标状态即时切换
- [ ] 提交成功后提示"已记录"；点击已选按钮可取消并将反馈表字段置为 `0`，点击另一按钮可切换
- [ ] 刷新后（重新加载会话）反馈状态仍保留

## 5. 效果评估（/eval）

- [ ] 知识库下拉默认选中第一个知识库
- [ ] 无标准问题时数据集表格为空，可"添加问题"
- [ ] 添加问题：问题、期望答案、目标 chunk（多选，可搜索）保存成功
- [ ] 编辑问题回显原值并可修改
- [ ] 删除问题有确认且成功后刷新
- [ ] 输入评估版本号（默认当前时间）后点击"运行评估"能完成
- [ ] 评估完成后最新报告展示：Hit Rate@5、MRR@5、Faithfulness、Answer Relevancy、Context Recall、Context Precision、拒答率
- [ ] 成功/部分成功/失败计数展示
- [ ] 评估历史列表按版本记录，切换知识库后数据跟随变化

## 6. 成本监控（/dashboard）

- [ ] 页面加载后展示估算成本（¥）与总 Token 数
- [ ] 七类 Token 均展示数值与占比：输入、回答生成、意图识别、Embedding、HyDE、Reranker、忠实度校验
- [ ] 横向占比条颜色分区正确，悬停显示数值
- [ ] 提问几条问题后点"刷新"，各类 Token 数值有增长
- [ ] 无统计数据时展示"暂无统计数据"

## 7. 权限隔离（重点）

用三个账号分别验证：

- [ ] `hr001` 只能看到 HR 知识库；`tech001` 只能看到 TECH 知识库；`admin` 可看到全部
- [ ] 公开知识库对任意登录用户只读（READ），不可写（上传/删除被拒）
- [ ] WRITE 账号可上传/重建/删除文档；READ 账号这些操作被拒
- [ ] READ 账号在聊天页不会看到无权限知识库选项
- [ ] 手动请求（curl）无权限知识库接口返回 403 或 404
- [ ] 多知识库请求中任一无权限则整体拒绝，不静默裁剪范围
- [ ] 未带 token 访问接口返回 401 并跳转登录页

## 8. 异常与降级场景

- [ ] 后端未启动时前端有错误提示，不白屏、不卡死
- [ ] Reranker 不可用/超时时查询仍返回 RRF 排序结果（观察后端日志确认降级）
- [ ] Redis 不可用时预算闸门返回 503 提示，前端展示错误
- [ ] 达到每日金额预算 100% 后新请求被拒绝，已开始请求正常完成
- [ ] 上传损坏 PDF 时文档状态为 FAILED，错误信息展示在状态列
- [ ] SSE 中途断连时前端提示"连接异常，请稍后重试"

## 9. 响应式与基础体验

- [ ] 浏览器宽度缩小时侧边栏变为底部导航，聊天知识库选择移到顶部
- [ ] 登录页在移动端隐藏左侧介绍区、保留表单
- [ ] 所有页面滚动、表格横向滚动正常，无布局溢出
