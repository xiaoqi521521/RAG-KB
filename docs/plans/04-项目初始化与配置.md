# 04-项目初始化与配置

本文基于 `docs/references/04-项目初始化与依赖配置.md`，将原 Spring Boot / Spring AI 项目初始化方案重构为 Python 3.12 / FastAPI / LangChain 版本。

原参考文件中的核心内容是：

- `pom.xml`：一次性配齐 Web、Spring AI、PostgreSQL、PGVector、Redis、MinIO、文档解析、Token 计数、权限、监控、重试和测试依赖。
- `application.yml`：集中配置数据库、Redis、异步任务、文件上传、DashScope、RAG 参数、Reranker、权限、监控和日志。
- 启动主类：开启 Web 应用、异步任务和重试。
- 核心配置类：线程池、Redis、MinIO、UserContext。

LangChain 重构后，对应为：

- `pyproject.toml`：使用 `uv` 管理 Python 依赖。
- `.env` / `app/core/config.py`：使用环境变量和 `pydantic-settings` 管理配置。
- `app/main.py`：FastAPI 应用入口，使用 `lifespan` 初始化和释放资源。
- `app/core/clients.py`：统一初始化 LangChain、Redis、MinIO、Reranker 等外部客户端。
- `app/core/context.py`：使用 `contextvars.ContextVar` 替代 Java `ThreadLocal`。

- `repositories/` 负责数据库访问，复杂检索允许使用原生 SQL。

## 五、FastAPI 启动入口

`app/main.py` 替代原 Spring Boot 启动主类。FastAPI 当前推荐用 `lifespan` 统一处理启动和关闭逻辑。

```python
from contextlib import asynccontextmanager

from fastapi import FastAPI
from prometheus_fastapi_instrumentator import Instrumentator

from app.api.router import api_router
from app.core.clients import close_clients, init_clients
from app.core.config import get_settings


@asynccontextmanager
async def lifespan(app: FastAPI):
    settings = get_settings()
    await init_clients(settings)
    yield
    await close_clients()


def create_app() -> FastAPI:
    settings = get_settings()
    app = FastAPI(
        title=settings.app_name,
        debug=settings.debug,
        lifespan=lifespan,
    )
    app.include_router(api_router, prefix=settings.api_v1_prefix)
    if settings.enable_metrics:
        Instrumentator().instrument(app).expose(app, endpoint="/metrics")
    return app


app = create_app()
```

## 六、数据库配置

`app/core/database.py`：

```python
from collections.abc import AsyncIterator

from sqlalchemy.ext.asyncio import AsyncSession, async_sessionmaker, create_async_engine
from sqlalchemy.orm import DeclarativeBase

from app.core.config import get_settings

settings = get_settings()

engine = create_async_engine(
    settings.database_url,
    echo=settings.db_echo,
    pool_size=settings.db_pool_size,
    max_overflow=settings.db_max_overflow,
    pool_pre_ping=True,
)

AsyncSessionLocal = async_sessionmaker(
    bind=engine,
    expire_on_commit=False,
    autoflush=False,
)


class Base(DeclarativeBase):
    pass


async def get_db() -> AsyncIterator[AsyncSession]:
    async with AsyncSessionLocal() as session:
        try:
            yield session
            await session.commit()
        except Exception:
            await session.rollback()
            raise
```

## 七、外部客户端配置

`app/core/clients.py` 统一管理长生命周期客户端，替代 Java 的 `RedisConfig`、`MinioConfig` 和 Spring AI Bean 配置。

```python
from typing import Any

import redis.asyncio as redis
from langchain_openai import ChatOpenAI, OpenAIEmbeddings
from minio import Minio

from app.core.config import Settings

_clients: dict[str, Any] = {}


async def init_clients(settings: Settings) -> None:
    _clients["redis"] = redis.from_url(settings.redis_url, decode_responses=True)
    _clients["minio"] = Minio(
        endpoint=settings.minio_endpoint,
        access_key=settings.minio_access_key,
        secret_key=settings.minio_secret_key,
        secure=settings.minio_secure,
    )
    _clients["chat_model"] = ChatOpenAI(
        model=settings.chat_model,
        api_key=settings.openai_api_key or settings.dashscope_api_key,
        base_url=settings.openai_base_url,
        temperature=settings.chat_temperature,
        max_tokens=settings.chat_max_tokens,
    )
    _clients["embeddings"] = OpenAIEmbeddings(
        model=settings.embedding_model,
        api_key=settings.openai_api_key or settings.dashscope_api_key,
        base_url=settings.openai_base_url,
    )


async def close_clients() -> None:
    redis_client = _clients.get("redis")
    if redis_client is not None:
        await redis_client.aclose()
    _clients.clear()


def get_redis() -> redis.Redis:
    return _clients["redis"]


def get_minio() -> Minio:
    return _clients["minio"]


def get_chat_model() -> ChatOpenAI:
    return _clients["chat_model"]


def get_embeddings() -> OpenAIEmbeddings:
    return _clients["embeddings"]
```

说明：

- DashScope 使用 OpenAI-compatible API，因此 `ChatOpenAI` 和 `OpenAIEmbeddings` 通过 `base_url` 接入。
- Reranker 不强行塞进 LangChain，建议使用 `httpx` 单独封装，便于设置超时、重试和降级。
- MinIO Python SDK 是同步客户端，若在高并发下载大文件时阻塞事件循环，应放入线程池或封装异步任务。

## 八、请求上下文配置

原 Java 版本使用 `ThreadLocal UserContext`。Python/FastAPI/asyncio 下使用 `contextvars.ContextVar`。

`app/core/context.py`：

```python
from contextvars import ContextVar
from dataclasses import dataclass


@dataclass(frozen=True)
class CurrentUser:
    user_id: int
    department_id: str
    role: str

    @property
    def is_admin(self) -> bool:
        return self.role == "ADMIN"


current_user_var: ContextVar[CurrentUser | None] = ContextVar(
    "current_user",
    default=None,
)


def get_current_user_from_context() -> CurrentUser:
    user = current_user_var.get()
    if user is None:
        raise RuntimeError("CurrentUser is not initialized")
    return user
```

`ContextVar` 只用于在 Service、LangChain Tool、Callback、日志链路中读取当前请求上下文。权限安全仍必须在 Repository SQL 中通过 `tenant_id` / `kb_id` 硬过滤。

## 九、认证依赖骨架

`app/api/dependencies.py`：

```python
from collections.abc import AsyncIterator

from fastapi import Depends, HTTPException, status
from fastapi.security import OAuth2PasswordBearer
from sqlalchemy.ext.asyncio import AsyncSession

from app.core.config import get_settings
from app.core.context import CurrentUser, current_user_var
from app.core.database import get_db

settings = get_settings()
oauth2_scheme = OAuth2PasswordBearer(tokenUrl=f"{settings.api_v1_prefix}/auth/login")


async def get_current_user(
    db: AsyncSession = Depends(get_db),
    token: str = Depends(oauth2_scheme),
) -> AsyncIterator[CurrentUser]:
    # TODO: 实现 JWT 验证，并从数据库加载 user_id、department_id、role。
    # 这里保留结构，避免后续 Service 直接依赖 HTTP token。
    if not token:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Not authenticated",
        )

    user = CurrentUser(
        user_id=1,
        department_id="default",
        role="ADMIN",
    )
    token_var = current_user_var.set(user)
    try:
        yield user
    finally:
        current_user_var.reset(token_var)
```

后续所有需要登录态的接口通过 `Depends(get_current_user)` 初始化上下文。不要在模块导入时读取 `ContextVar`，只在请求链路内读取。

## 十、Reranker 客户端配置

`app/integrations/dashscope.py`：

```python
import httpx
from tenacity import retry, stop_after_attempt, wait_exponential

from app.core.config import get_settings


class DashScopeRerankerClient:
    def __init__(self) -> None:
        self.settings = get_settings()
        self.timeout = self.settings.reranker_timeout_ms / 1000

    @retry(wait=wait_exponential(multiplier=0.2, max=1), stop=stop_after_attempt(2))
    async def rerank(self, query: str, documents: list[str]) -> list[float]:
        payload = {
            "model": self.settings.reranker_model,
            "input": {
                "query": query,
                "documents": documents,
            },
            "parameters": {
                "top_n": self.settings.reranker_top_n,
            },
        }
        headers = {
            "Authorization": f"Bearer {self.settings.dashscope_api_key}",
            "Content-Type": "application/json",
        }
        async with httpx.AsyncClient(timeout=self.timeout) as client:
            response = await client.post(
                self.settings.reranker_endpoint,
                json=payload,
                headers=headers,
            )
            response.raise_for_status()
            data = response.json()
        return [item["relevance_score"] for item in data["output"]["results"]]
```

Reranker 超时或失败时，业务层必须降级为 RRF TopN，不应让问答接口整体失败。

## 十二、与原 Spring 配置的对应关系

| Spring AI 版本 | LangChain 重构版本 |
| --- | --- |
| `pom.xml` | `pyproject.toml` |
| `application.yml` | `.env.example` + `app/core/config.py` |
| `RagKbApplication` | `app/main.py` |
| `@EnableAsync` | `BackgroundTasks`，生产可替换 Celery / Dramatiq |
| `@EnableRetry` | `tenacity` |
| `AsyncConfig` | 异步任务队列 / 后台任务配置 |
| `RedisConfig` | `redis.asyncio.from_url()` |
| `MinioConfig` | `Minio(...)` 客户端 |
| Spring AI `ChatClient` | `langchain_openai.ChatOpenAI` |
| Spring AI `EmbeddingModel` | `langchain_openai.OpenAIEmbeddings` |
| WebFlux Reranker 调用 | `httpx.AsyncClient` |
| Sa-Token | JWT + FastAPI dependency |
| `UserContext ThreadLocal` | `contextvars.ContextVar[CurrentUser]` |
| Actuator health | FastAPI health route |
| Micrometer Prometheus | `prometheus-fastapi-instrumentator` |
