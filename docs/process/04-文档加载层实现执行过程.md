## 解析器说明

### TxtParser

职责：

- 读取 TXT 字节内容。
- 优先 UTF-8 解码，异常字符比例较高时尝试 GBK。
- 统一换行为 `\n`。
- 去除 BOM。
- 空文本抛出 `EmptyDocumentError`。
- 疑似二进制文本抛出 `DocumentParseError`。
- 返回 1 个 LangChain `Document`。

metadata：

```plain
source
file_type
page_num
parser
```

### MarkdownParser

职责：

- 读取 Markdown 文本。
- 按一级、二级标题切分逻辑章节。
- 代码块内的 `#` 不作为标题。
- 清理基础 Markdown 标记。
- 图片替换为 `[图片]`。
- 代码块替换为 `[代码块]`。
- 每个章节返回 1 个 LangChain `Document`。

metadata：

```plain
source
file_type
page_num
parser
section_title
title
```

其中 `section_title` 和 `title` 仅在可识别时写入。

### MinerUDocumentParser

职责：

- 读取 MinerU 配置。
- 使用官方 `langchain-mineru` 的 `MinerULoader` 加载 PDF / Word。
- PDF 使用 `split_pages=True`，由官方 SDK 返回一页一个 `Document`。
- Word 使用 `split_pages=False`，由官方 SDK 返回单文档结果。
- 将官方 SDK 返回的 metadata 收敛为项目统一 metadata。

当前实现说明：

- 新增依赖 `langchain-mineru`。
- 默认集成模式为 `MINERU_MODE=sdk`。
- 默认解析模式为 `MINERU_API_TYPE=precision`。
- 官方 SDK 默认不需要配置 `MINERU_API_URL`，该字段保留为空，后续如接入自部署服务再使用。
- 测试使用 fake `MinerULoader`，不依赖真实 MinerU 服务。

## 统一入口

新增 `DocumentLoaderService`：

```plain
load(file, file_name) -> list[Document]
```

行为：

- 根据文件扩展名识别文件类型。
- 根据文件类型分发到对应解析器。
- 成功返回非空 `list[Document]`。
- 不支持文件类型抛出 `UnsupportedFileTypeError`。
