# 01 — 提取共享 RAG 执行接口

**What to build:** 让线上 V4 问答通过一次 RAG 执行同时形成现有公开响应和仅供内部消费的精排候选、实际参考内容、拒答状态及 Reranker 降级状态。评估模块后续可以消费同一份执行结果，而无需重复检索、精排或生成。

**Blocked by:** None — can start immediately

**Status:** resolved

- [x] 共享执行接口只执行一次检索、Reranker、上下文准备和回答生成。
- [x] 内部结果包含过滤前的精排候选、真正进入回答模型的逐条参考内容、明确拒答状态和 Reranker 降级信息。
- [x] 参考内容保留实际字符或 Token 裁剪结果，不暴露已经移除的完整 chunk 文本。
- [x] 线上 V4 继续返回现有回答、引用、命中数量和耗时结构。
- [x] 内部排名、参考内容和降级诊断不进入公开 RAG 响应。
- [x] 线上正常回答继续执行现有抽样忠实性观测，明确拒答继续跳过。
- [x] 现有权限、HyDE、混合检索、RRF、Reranker 降级、置信度过滤、上下文裁剪、引用和拒答行为没有回归。
- [x] 测试通过共享执行接口和公开 V4 行为验证结果，不断言私有方法调用顺序。
