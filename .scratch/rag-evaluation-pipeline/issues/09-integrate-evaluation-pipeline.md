# 09 — 完成评估流水线集成与运行说明

**What to build:** 把检索与生成评估、标准问题生命周期、文档重建失效、反馈候选和 Trace ID 作为一个可运行工作流完成回归验证，并提供管理员通过数据库安全审核和激活候选的操作说明。

**Blocked by:** 05 — 接入四项生成评估指标; 06 — 文档发布时使旧标注失效; 07 — 记录回答反馈并形成候选闭环; 08 — 增加请求 Trace ID

**Status:** resolved

- [x] 完整工作流可从创建标准问题、标注 chunk、运行版本、查看聚合报告走通。
- [x] 单知识库差评可形成候选，并能追溯原反馈、助手回答和引用而不复制回答正文。
- [x] 提供候选或待审核问题转为 `ACTIVE` 前的只读校验 SQL 和状态更新 SQL。
