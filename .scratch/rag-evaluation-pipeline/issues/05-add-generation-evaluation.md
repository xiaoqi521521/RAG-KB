# 05 — 接入四项生成评估指标

**What to build:** 在正式同步评估中使用同一次 RAG 执行的实际回答和实际参考内容计算四项 RAGAS 生成指标，并让拒答、精排降级和单项失败按照已确认的空值及聚合语义呈现。

**Blocked by:** 02 — 建立可运行的 RAGAS 评估适配器; 04 — 运行检索评估并比较版本

**Status:** resolved

- [x] 有期望答案、非明确拒答且 Reranker 未降级的问题调用 RAGAS 适配器。
- [x] Faithfulness 使用问题、实际回答和实际参考内容。
- [x] Answer Relevancy 使用问题和实际回答。
- [x] Context Recall 和 Context Precision 使用问题、期望答案和实际参考内容。
- [x] 实际参考内容与回答模型看到的内容一致，不重新检索、不使用完整原始 chunk，也不缩小为最终引用子集。
- [x] 缺少期望答案时四项生成指标为空，不调用 RAGAS，且不因此标记部分失败。
- [x] 明确拒答时四项生成指标为空，不调用 RAGAS，并保存项目固定拒答回答。
- [x] 任意 Reranker 降级时四项生成指标为空，不调用 RAGAS。
- [x] 单项 RAGAS 失败只使对应指标为空，保留其他有效指标，并把题目标记为 `PARTIAL`。
- [x] 持久化错误类型保持低基数，具体失败指标和降级原因只进入不含敏感正文的安全日志。
- [x] 历史报告为每项生成指标分别返回样本数和平均值，没有样本时平均值为空。
- [x] 历史报告通过固定实际回答计算拒答数量，并以本版本总问题数计算拒答率。
- [x] 正常生成指标、拒答和 Reranker 降级不会触发现有线上抽样忠实性观测。
- [x] 测试覆盖四项输入、指标部分失败、拒答、降级跳过、独立分母和拒答聚合。
