# 04 — 隔离对话会话

**What to build:** 将对话会话变成只属于创建用户的资源。用户只能复用、浏览、更新和写入自己的对话会话与消息；包括系统管理员在内的其他用户不能通过已知 `session_id` 查看或污染会话。

**Blocked by:** 01 — 建立可信当前用户

**Status:** resolved

- [x] 会话复用、活跃时间更新、历史读取和保存完整问答轮次均验证会话所有者与当前用户一致。
- [x] 不存在、已删除或不属于当前用户的会话在复用和消息读取时返回 `404`。
- [x] 系统管理员不默认绕过对话会话所有权；跨用户审计读取仍不提供。
- [x] 用户仍可读取自己的既有对话历史，即使其后失去某个知识库的读权限；任何新问答仍由当前请求权限控制。
- [x] 以两个普通用户和一个系统管理员的路由及仓储行为测试证明无法跨用户读写会话。
