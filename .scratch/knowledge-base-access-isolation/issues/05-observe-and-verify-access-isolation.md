# 05 — 观测并验证权限隔离

**What to build:** 为已完成的知识库级逻辑隔离提供最小化安全观测和完整回归验证，使运维人员能了解权限检查、拒绝和耗时，而不在日志或指标中泄露知识库内容或高基数敏感标识。

**Blocked by:** 02 — 统一知识库读写授权; 03 — 强制 RAG 已授权知识库范围; 04 — 隔离对话会话

**Status:** resolved

- [x] 记录权限检查的操作、结果、权限来源和耗时，并能区分认证失败、拒绝与依赖不可用。
- [x] 日志和指标不包含 JWT、完整问题、文档正文、chunk、会话消息、Prompt、密钥或用户和资源 ID 等高基数标签。
