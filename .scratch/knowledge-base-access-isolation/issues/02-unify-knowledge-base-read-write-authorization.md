# 02 — 统一知识库读写授权

**What to build:** 让知识库与文档操作统一依据有效权限执行：系统管理员全局生效，公开知识库仅可读，用户和部门授权取最高等级，局部 `ADMIN` 只管理对应知识库；新知识库创建者获得局部 `ADMIN`。

**Blocked by:** 01 — 建立可信当前用户

**Status:** resolved

- [x] 系统管理员、公开读、用户授权、部门授权及其最高等级合并在所有知识库读写入口行为一致。
- [x] `READ` 用户可访问文档列表、状态和下载，但不能上传、替换、删除或重建；`WRITE` 与局部 `ADMIN` 可执行这些写操作。
- [x] 知识库创建与创建者局部 `ADMIN` 授权属于同一工作单元，归属部门不隐式获得写权限。
- [x] 不存在、已删除或与路径知识库不匹配的文档按 `404` 处理；明确无有效权限返回 `403`。
- [x] 权限数据依赖故障返回 `503` 且不执行文档、索引或存储操作。
- [x] 路由与权限服务行为测试覆盖有效权限矩阵和文档嵌套资源范围。
