# 01 — 建立可信当前用户

**What to build:** 让受保护的知识库 API 从经验证 JWT 中识别用户，并由身份提供者实时加载启用状态、部门和系统角色，形成可信的当前用户；身份无效或身份依赖不可用时在任何业务操作前安全结束请求。

**Blocked by:** None — can start immediately.

**Status:** resolved

- [x] 缺失、无效或过期 JWT 返回 `401`，不建立当前用户、不调用业务服务。
- [x] 有效 JWT 只用于识别用户，当前部门、系统角色和启用状态由身份提供者在每个新请求中加载。
- [x] 用户不存在或已停用时拒绝访问，且请求上下文在请求结束后被清理。
- [x] 身份提供者不可用时返回 `503`，不将无法判断的身份视为已授权。
- [x] 既有受保护路由能使用新的当前用户依赖，测试通过路由边界验证状态码和下游未调用行为。

## Comments

- 已实现 JWT 解码、可替换身份提供者和请求上下文清理；未接入用户目录时显式返回 `503`。
- `uv run pytest tests/api/test_dependencies.py -v`、相关 API 回归和 Ruff 通过。Mypy 仍受现有 Settings 工厂与第三方存根缺失阻塞。
