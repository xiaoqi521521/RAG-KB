# 03 — 非阻断忠实性抽样评估

**What to build:** 对符合条件的 V4 正常回答进行可配置的抽样忠实性评估，形成可观测的质量信号，同时保证评估超时、失败或判定不忠实时都不会改写、拒绝或破坏用户回答。

**Blocked by:** 02 — 引用容错与拒答一致性

**Status:** ready-for-agent

- [ ] 忠实性评估复用现有回答模型和凭证，不新增独立评估模型或客户端
- [ ] 抽样率支持 `0` 到 `1`，默认值为 `0.2`；`0` 关闭评估，`1` 评估全部符合条件的回答
- [ ] 忠实性评估使用独立超时，默认 5 秒
- [ ] 忠实性评估不执行重试
- [ ] 明确拒答不进入忠实性评估
- [ ] 评估结果能够区分忠实、不忠实、评估失败和抽样跳过
- [ ] 有效评估分数归一化到 `0` 至 `1`，评估失败时分数为空
- [ ] 超时、模型异常和输出格式无法解析均记为评估失败，不伪装为忠实结果
- [ ] 不忠实和评估失败都不修改最终回答、来源和命中数量
- [ ] 记录评估状态、分数分布、评估耗时、抽样情况和额外生成 Token
- [ ] 日志不包含完整问题、回答、参考内容、评估 Prompt、密钥或连接信息
- [ ] 忠实性状态和分数不进入公开查询响应，也不写入数据库
- [ ] 通过公共评估接口、V4 查询接口和 API 测试验证抽样、超时、错误隔离和响应兼容性
