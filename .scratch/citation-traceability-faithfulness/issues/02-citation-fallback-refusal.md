# 02 — 引用容错与拒答一致性

**What to build:** 在引用缺失、部分错误或全部错误时保持知识库问答可用，并让拒答、来源和命中数量保持一致。引用后处理不得增加模型或 Embedding 调用，也不得因解析异常让主查询失败。

**Blocked by:** 01 — 标准引用与精确来源闭环

**Status:** resolved

- [x] 正常回答完全没有引用标记时，返回本次实际提供给回答模型的全部参考内容作为兜底来源
- [x] 无标注兜底不触发额外模型调用、Embedding 调用或重新检索
- [x] 有效和无效引用编号混合时，忽略无效编号，只返回有效来源
- [x] 存在引用标记但全部编号无效时，正常返回原回答、空来源和零命中数量
- [x] 无效或越界编号不会导致数组越界、服务异常或用户请求失败
- [x] 明确知识库拒答统一转换为项目固定拒答文案
- [x] 明确拒答返回空来源和零命中数量，不触发无标注兜底
- [x] 仅说明某个次要信息未找到的正常回答不会被误判为整体拒答
- [x] 引用结果能够区分精确引用、全部来源兜底、全部无效和拒答
- [x] 日志记录引用结果及有效、无效数量，但不记录完整问题、回答或参考内容
- [x] 权限过滤后的参考内容范围不会因引用容错而扩大
- [x] 通过公共 V4 查询和 API 行为测试覆盖全部边界分支，并保持原有拒答和权限测试通过
