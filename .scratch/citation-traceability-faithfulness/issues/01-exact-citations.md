# 01 — 标准引用与精确来源闭环

**What to build:** 让 V4 回答从严格引用生成一路贯通到公开查询响应。模型应使用统一引用格式，回答中的有效引用能够准确映射为结构化引用来源；流程、列表、编号和条件必须保留实际可见内容及顺序，不能被空泛概括替代。

**Blocked by:** None — can start immediately

**Status:** resolved

- [x] V4 使用独立引用型 Prompt，旧查询管道继续保持现有 Prompt 行为
- [x] Prompt 要求每条事实使用 `（来源：[参考N]）`，并支持同一事实引用多个参考内容
- [x] Prompt 明确禁止使用通用知识补全公司制度，并在参考内容不足时要求拒答
- [x] Prompt 要求步骤、编号、条件和列表按实际可见内容完整、有序回答，不能使用空泛概括替代
- [x] 标准引用格式和现有裸 `[参考N]` 格式都能够被识别
- [x] 多个和重复引用能够全部提取、去重，并保持首次出现顺序
- [x] 存在有效引用时，公开响应只返回这些引用对应的来源
- [x] 每条来源包含原始参考编号，以及最多 200 字符的实际上下文摘要
- [x] 来源继续保留文档、知识库、chunk、页码、章节、chunk 序号和排序分等现有溯源信息
- [x] 上下文被裁剪时，来源摘要不展示未提供给回答模型的后续文本
- [x] `hit_count` 等于最终来源数量，公开查询响应的其他顶层字段保持不变
- [x] 通过公共引用解析、来源构建、V4 查询和 API 行为测试验证完整闭环
