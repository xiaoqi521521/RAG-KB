# 02 — 流式返回首轮知识库回答

**What to build:** 用户可以通过 SSE 发起首轮知识库问答，立即获得会话标识和检索状态，随后接收流式回答，并在成功完成后获得引用来源、耗时和已保存的首轮对话记录。

**Blocked by:** 01 — 提取可复用的 V4 回答准备流程.

**Status:** ready-for-agent

- [x] 正常问答依次返回检索状态、生成状态、文本片段和带引用来源及耗时的完成事件。
- [x] 未提供会话标识时会创建对话会话，并在首个状态事件中返回它。
- [x] 成功完成后保存 USER 和 ASSISTANT 消息、首轮标题、引用来源、耗时和可用的生成 token。

## Comments

- 已实现 SSE 首轮成功路径；路由和服务行为测试覆盖事件契约、成功持久化与 token 统计。
